🚀 CLI Setup

Follow these steps to authenticate and start using Mythos.

1 Install Ollama and Python 3.10+
2 Clone the repo:
git clone https://github.com/samkomedved319-dev/Mythos.git
cd Mythos
3 Install dependencies & build model:
pip install -r requirements.txt
ollama create mythos -f Modelfile
4 Run the CLI and authenticate:
python mythos_cli.py
Enter your email and token when prompted.
